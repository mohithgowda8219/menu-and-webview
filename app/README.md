# Experiment 8: Implementing Menus and WebView in Android

Android app demonstrating an Options Menu combined with WebView to browse web pages within the app.

## Output
![App Screenshot](screenshot.png)

## Description
- WebView loads a default web page (Google)
- Options Menu (main_menu.xml) provides: Home, Wikipedia, About, Exit
- Selecting a menu item loads the corresponding URL in WebView
- Back button navigates through WebView history before exiting the app
